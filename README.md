# Rosetta — 企业数据治理平台

用一种逻辑定义，翻译为多种数据库方言。

## 快速开始

```bash
# 1. 启动 MySQL
docker compose up -d mysql

# 2. 启动服务
cd backend && go run .

# 3. 打开浏览器
# http://localhost:8080
```

## 技术栈

- **后端**: Go 1.26 + Gin + GORM
- **数据库**: MySQL 8.0 (生产) / SQLite (开发)
- **前端**: 纯原生 JS + CSS，零框架依赖
- **部署**: Docker Compose

## 配置

编辑 `backend/config.yaml`:

```yaml
database:
  type: mysql          # sqlite (开发) / mysql (生产)
  host: 127.0.0.1
  port: 3306
  user: root
  password: <your-password>
  dbname: rosetta

jwt:
  secret: "your-secret"
  expire_hours: 24
```

环境变量覆盖: `ROSETTA_DB_PASSWORD`, `ROSETTA_JWT_SECRET`, `ROSETTA_SERVER_PORT`

## API 概览

| 模块 | 端点前缀 | 数量 |
|------|----------|:--:|
| 认证 | `/api/auth` | 3 |
| 用户管理 | `/api/users`, `/api/roles` | 11 |
| 实例管理 | `/api/instances` | 8 |
| 字典维护 | `/api/dicts` | 10 |
| 模型管理 | `/api/models` | 16 |
| 反向工程 | `/api/instances/:id/tables`, `/api/models/reverse-engineer` | 3 |
| 可视化 | `/api/models/:id/structure-diagram`, `/api/schemas/:id/er-diagram` | 2 |

## DDL 方言支持

| 特性 | MySQL | GaussDB M |
|------|-------|-----------|
| 自增主键 | AUTO_INCREMENT | GENERATED BY DEFAULT AS IDENTITY |
| 日期时间 | DATETIME | TIMESTAMP |
| 大文本 | TEXT | CLOB |
| 布尔 | TINYINT(1) | BOOLEAN |
| 注释 | 内联 COMMENT | COMMENT ON 独立语句 |

## 项目结构

```
rosetta/
├── docker-compose.yml
├── docs/design.md
├── backend/
│   ├── main.go
│   ├── config/      # Viper 配置
│   ├── database/    # GORM + AutoMigrate + Seeder
│   ├── models/      # 14 个数据模型
│   ├── service/     # 7 个业务服务
│   ├── handler/     # 7 个路由处理器
│   ├── middleware/  # JWT + RBAC + Audit
│   ├── ddl/         # DDL 渲染引擎 (MySQL + GaussDB)
│   └── utils/       # JWT + 响应格式
└── frontend/
    ├── index.html
    ├── css/style.css
    └── js/
        ├── api.js           # HTTP 客户端
        ├── router.js        # Hash 路由
        ├── app.js           # 布局 + 工具
        └── pages/           # 7 个页面模块
```
